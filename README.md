Aura is a personal game project built in Unity with C#. The goal is a PvP fighting game where characters wield aura-based powers in fast, hands-on combat, with customizable appearances and detailed, scenic maps.

Combat is inspired by Mortal Kombat.

Current features
Player character with movement
Walking and idle animations
Camera that follows the character
Planned features
PvP combat
Aura-based powers for each character
Customizable character appearances
Landscaped maps and environments
Built with
Unity
C#
Status

Early development. I'm building Aura to learn game development and C# alongside my software engineering coursework
